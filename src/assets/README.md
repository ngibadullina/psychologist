# src/assets

Сюда кладём изображения, которые обрабатывает Astro: фотографию психолога,
обложки статей, иллюстрации разделов.

Такие файлы импортируются в компонентах и выводятся через `<Image />` из `astro:assets`:
Astro сам подберёт размеры, сгенерирует WebP/AVIF и подставит `width`/`height`.

Что положить сюда позже:

- `portrait.jpg` — фотография для первого экрана (рекомендуется от 1200 px по ширине);
- `blog/` — обложки статей (рекомендуется 1200×630 для корректного Open Graph).

Файлы, которым обработка не нужна (favicon, PDF, robots.txt), кладём в `public/`.
