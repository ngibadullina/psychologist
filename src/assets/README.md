# src/assets

Изображения, которые обрабатывает Astro: логотип для шапки и фотография.

Такие файлы импортируются в компонентах и выводятся через `<Image />` из `astro:assets`:
Astro сам подберёт размеры, сгенерирует WebP/AVIF и подставит `width`/`height`.

- `portrait.jpg` — фотография для первого экрана и страницы «Про мене»
  (портретная ориентация, от 1000 px по ширине);
- `logo.png` — логотип в шапке, генерируется командой `npm run icons`.

Обложки и картинки статей сюда не кладём: они лежат рядом с текстом статьи,
в папке `src/content/blog/<slug>/` (см. AGENTS.md, «Как добавить статью»).

Файлы, которым обработка не нужна (favicon, PDF), кладём в `public/`.
