# Сайт-визитка психолога

Статический сайт на Astro + TypeScript, без backend. Публикация — GitHub Pages.

## Требования

- Node.js >= 22.12
- npm

## Команды

| Команда                | Действие                                          |
| ---------------------- | ------------------------------------------------- |
| `npm install`          | установить зависимости                            |
| `npm run dev`          | сервер разработки на `localhost:4321`             |
| `npm run dev:host`     | то же, но доступно с других устройств в сети      |
| `npm run build`        | production-сборка в `dist/`                       |
| `npm run preview`      | просмотр собранного сайта                         |
| `npm run preview:host` | то же, но доступно с других устройств в сети      |
| `npm run build:offline`| автономная сборка в `dist-offline/` для просмотра с диска |
| `npm run icons`        | пересобрать логотип и фавиконки                   |
| `npm run og`           | пересобрать картинку превью ссылки `og-image.jpg` |
| `npm run check`        | проверка типов и `.astro`-файлов                  |

## Просмотр с телефона и других устройств

```
npm run dev:host
```

Astro выведет два адреса — берите строку `Network`:

```
Local    http://localhost:4321/
Network  http://192.168.1.5:4321/
```

Этот адрес открывается на телефоне, планшете или другом компьютере.

Условия:

- устройства в одной сети Wi-Fi, компьютер не в режиме гостевой сети;
- компьютер с запущенным сервером остаётся включённым;
- при первом запуске Windows спросит разрешение брандмауэра — нужно разрешить
  доступ для частных сетей.

`npm run dev:host` показывает версию для разработки. Чтобы посмотреть то, что
реально уедет на GitHub Pages, соберите и запустите просмотр:

```
npm run build
npm run preview:host
```

## Структура проекта

```
public/              статические файлы без обработки (favicon, og-image, CNAME)
src/
  assets/            изображения, которые обрабатывает Astro
  components/        небольшие переиспользуемые компоненты
  config/            централизованные настройки: контакты, навигация, адрес сайта
  content/blog/      статьи блога, одна папка на статью
  content.config.ts  поля статьи (Astro Content Collections)
  layouts/           макеты страниц
  pages/             маршруты сайта; robots.txt и rss.xml тоже генерируются здесь
  styles/            дизайн-система и глобальные стили
  utils/             небольшие хелперы (ссылки с учётом base, выборка статей)
scripts/             генерация иконок, превью ссылки и офлайн-сборки
astro.config.ts      конфигурация Astro: site, base, интеграции
```

## Статьи блога

Одна статья — одна папка `src/content/blog/<slug>/` с файлом `index.md`
и картинками рядом. Адрес статьи — `/blog/<slug>/`.

Пошаговая инструкция с шаблоном и описанием полей — в [`AGENTS.md`](AGENTS.md),
раздел «Как добавить статью».

## Настройка публикации

Адрес сайта задаётся в одном месте — [`src/config/site.ts`](src/config/site.ts):

```ts
export const SITE_URL = 'https://gibadullina.com';
export const BASE_PATH = '/';
```

- Собственный домен: `SITE_URL = 'https://example.com'`, `BASE_PATH = '/'`
- GitHub Pages в подпапке: `SITE_URL = 'https://USERNAME.github.io'`, `BASE_PATH = '/REPOSITORY'`

Сам домен привязывается файлом [`public/CNAME`](public/CNAME): GitHub Pages читает
его из собранного сайта при каждой выкладке. Меняете домен — меняете эти три места.

Локальный адрес сайта при `npm run dev` — `http://localhost:4321/`.

Все внутренние ссылки и пути к файлам из `public/` строятся через `withBase()`
из [`src/utils/url.ts`](src/utils/url.ts), поэтому смена сценария не требует правок в компонентах.
