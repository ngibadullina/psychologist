# Сайт психолога Наталії Гібадулліної

Сайт-визитка с блогом: <https://gibadullina.com>. Статический Astro 7 + TypeScript,
обычный CSS, без backend и без UI-фреймворков. Публикация — GitHub Pages:
каждый push в `main` собирает и выкладывает сайт (`.github/workflows/deploy.yml`).

Этот файл — для агентов. `CLAUDE.md` — ссылка на него. Для людей — `README.md`.

## Языки

- **Тексты на сайте — только украинский.** Ни слова по-русски в вёрстке и статьях.
- Комментарии в коде, документация, сообщения коммитов — по-русски.
- Коммиты: короткая фраза в повелительном наклонении — «Добавить статью «…»»,
  «Выровнять первый экран по верхнему краю».

## Команды

| Команда                 | Что делает                                          |
| ----------------------- | --------------------------------------------------- |
| `npm run dev`           | сервер разработки, `http://localhost:4321/`         |
| `npm run check`         | проверка типов и `.astro`-файлов                    |
| `npm run build`         | production-сборка в `dist/`                         |
| `npm run build:offline` | сборка для просмотра с диска в `dist-offline/`      |
| `npm run og`            | пересобрать `public/og-image.jpg` (превью ссылки)   |
| `npm run icons`         | пересобрать логотип и фавиконки                     |

Сервер разработки агенту запускать в фоне:

```sh
astro dev --background
```

Управление: `astro dev stop`, `astro dev status`, `astro dev logs`.

**Работа закончена, когда** `npm run check` и `npm run build` проходят без ошибок.

## Правила

- Внутренние ссылки и пути к файлам из `public/` — только через `withBase()`.
- В CSS — только переменные из `tokens.css`, никаких «случайных» цветов и отступов.
- Не добавлять зависимости и фреймворки без явной необходимости; если нужно — сначала
  спросить владельца и объяснить зачем.
- Не выдумывать профессиональные сведения: дипломы, сертификаты, отзывы, опыт,
  медицинские утверждения. Только то, что дал владелец.
- Секретов и токенов в коде быть не должно: всё попадает в клиентскую сборку.
- Не переписывать работающие части без причины.

## Как добавить статью

Статьи — Markdown-файлы в Astro Content Collections. Всё остальное происходит само:
статья появится в списке `/blog/`, в блоке «Останні статті» на главной, в RSS
(`/rss.xml`), в sitemap, получит мета-теги, Open Graph и разметку `BlogPosting`.

### 1. Получить текст

Исходники статей лежат в `__assets__/Статьи/<N. Название>/` (папка вне git).
Обычно там один и тот же документ в трёх форматах, выгруженных из Google Docs:

- **`.md` — брать текст отсюда**: разметка уже готова, нужна только чистка (шаг 4);
- **`.docx` — брать картинки отсюда**: в `.md` они уменьшены (~600 px),
  а в `.docx` лежат в исходном размере. `.docx` — это zip-архив, картинки в
  `word/media/`: `unzip -o "файл.docx" -d <временная папка>`;
- `.pdf` — только чтобы посмотреть, как задумана вёрстка.

Если статья пришла только ссылкой на Google Docs и документ открыт по ссылке,
его можно скачать в Markdown (`<ID>` — часть адреса между `/d/` и `/edit`):

```sh
curl -L "https://docs.google.com/document/d/<ID>/export?format=md" -o article.md
```

- Ответ `401` — документ закрыт. Попросить владельца открыть доступ
  («Усі, хто має посилання» → «Читач») или прислать файл `.docx` / `.md`.
- Картинки Google вставляет в конец Markdown-файла как base64
  (`[image1]: <data:image/png;base64,...>`), уменьшенными. Если есть `.docx` —
  брать оттуда; если нет — декодировать base64 в файл.
- Скачанный файл держать во временной папке, не в репозитории.

### 2. Придумать адрес (slug)

Адрес статьи — имя её папки: `src/content/blog/<slug>/` → `/blog/<slug>/`.

- Латиница, нижний регистр, слова через дефис, 3–6 слов.
- Украинский заголовок транслитерировать по официальной системе
  (КМУ 2010: г → h, ґ → g, и → y, і → i, ї → i, й → i, є → ie, ж → zh, х → kh,
  ц → ts, ч → ch, ш → sh, щ → shch, ю → iu, я → ia; в начале слова є/ї/й/ю/я →
  ye/yi/y/yu/ya; мягкий знак и апостроф опускаются).
- Пример: «Як упоратися з тривогою» → `yak-uporatysia-z-tryvohoiu`.
- **После публикации адрес не менять** — сломаются ссылки, которыми уже поделились.

### 3. Создать файл статьи

`src/content/blog/<slug>/index.md`:

```md
---
title: 'Як упоратися з тривогою'
description: 'Коротко про те, звідки береться тривога і що допомагає її прожити.'
publishDate: 2026-10-04
image: ./cover.jpg
imageAlt: 'Жінка сидить біля вікна з чашкою чаю'
category: 'Тривога'
tags: ['тривога', 'турбота про себе']
---

Перший абзац статті…

## Підзаголовок

Текст…
```

**В каждой статье обязательны пять полей: `title`, `description`, `publishDate`,
`category`, `tags`.** Это требование владельца, схема проверяет его при сборке.
Если автор чего-то не дал — составить самому по тексту статьи (на украинском),
а в отчёте перечислить, что составлено, и попросить подтвердить.

| Поле          | Обязательно | Что это                                                      |
| ------------- | ----------- | ------------------------------------------------------------ |
| `title`       | да          | заголовок статьи (он же `<h1>`)                              |
| `description` | да          | 1–2 предложения для поисковиков и карточки, до ~160 символов |
| `publishDate` | да          | дата публикации, `ГГГГ-ММ-ДД`                                |
| `updatedDate` | нет         | дата существенной правки уже опубликованной статьи           |
| `image`       | нет         | обложка, путь относительно файла: `./cover.jpg`             |
| `imageAlt`    | с обложкой  | описание обложки словами; без него сборка упадёт             |
| `category`    | да          | одна рубрика; брать уже существующие, новые — не плодить     |
| `tags`        | да          | хотя бы один тег, нижний регистр (кроме аббревиатур: `МАК`)  |
| `draft`       | нет         | `true` — черновик: виден в `npm run dev`, в production не попадает |
| `author`      | нет         | по умолчанию — имя психолога из `site.ts`                    |

Строки в frontmatter брать в одинарные кавычки: в украинских текстах встречаются
двоеточия и апострофы. Апостроф внутри слова — типографский `’` (`з’являється`).

Рубрики, которые уже есть: `Методи роботи`. Посмотреть актуальный список:
`grep -rh "^category:" src/content/blog`.

### 4. Перенести текст

- Текст статьи — авторский. Не переписывать и не «улучшать» смысл. Допустимо:
  форматирование, очевидные опечатки. Каждую правку текста перечислить в отчёте.
- `title` — это `<h1>`. В тексте его не повторять; подзаголовки начинаются с `##`.
- В документе может не быть заголовка (первая статья начиналась сразу с картинки
  и «Вступ»). Тогда составить его из слов самой статьи и вынести на согласование.
- Почистить артефакты Google Docs:
  - `## **Вступ**` → `## Вступ`: жирный внутри заголовков не нужен;
  - разделители `---` между разделами убрать — разделы и так отделены заголовками;
  - картинку из первой строки (`## **![][image1]**`) — сделать обложкой и убрать
    из текста; определение `[image1]: <data:...>` в конце файла удалить;
  - строку-заглушку кнопки «Записатися на консультацію» в конце удалить —
    страница статьи сама выводит кнопки записи под текстом;
  - лишние экранирования (`\-`, `\.`, `\!`), якоря `{#...}`, «заголовки» из
    жирного текста — заменить на `##`.
- Переносы строк внутри абзаца — авторский ритм, их **сохранять**. Google
  отмечает их двумя пробелами в конце строки; заменить на `\` в конце строки —
  пробелы незаметны и теряются при правке. Пример:

  ```md
  Карта не говорить.\
  Вона відображає.
  ```

- Списки — через `- `, без пробелов в конце пунктов.
- После переноса сверить текст с исходником пословно (скриптом): потеряться
  должны только убранные заглушки.
- Если `title`, `description`, `category` или `tags` автор не дал — составить
  по тексту на украинском и вынести на подтверждение (см. шаг 3).

### 5. Картинки

- Класть в папку статьи рядом с `index.md`: `cover.jpg`, `1.jpg`, …
- В тексте: `![Опис картинки](./1.jpg)` — описание обязательно.
- Обложка: горизонтальная, от 1200×630 px (такие пропорции у карточки и превью
  ссылки; остальное обрежется по центру). Форматы jpg, png, webp.
- Сжимать и конвертировать не нужно — Astro делает это сам.

### 6. Блог включён

Флаг `BLOG_ENABLED` в `src/config/site.ts` уже `true` (с первой статьи).
Если когда-нибудь удалят все статьи — вернуть `false`, иначе меню поведёт
на пустой раздел.

### 7. Проверить

1. `npm run check` и `npm run build` — без ошибок.
2. Открыть `http://localhost:4321/blog/<slug>/` и `/blog/` в `npm run dev`
   и посмотреть, как выглядит текст: заголовки, списки, картинки.
